# Version home 28-08

Snapshot van de herwerkte scoreboard-applicatie op 28 augustus 2026.

Deze map bevat de broncode en configuratie van de versie met de vernieuwde livebediening, flexibele console-indeling, sponsorbediening en snelle mediaknoppen. Gegenereerde builds, logs, lokale databases, gebruikersdata en `node_modules` zijn bewust niet opgenomen.

## Lokaal starten

```powershell
npm install
npm run dev
```

Gebruik voor productie of Electron de bestaande scripts in `package.json`.
